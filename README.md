# minishell

**Minishell** is a small Bash-like shell built from scratch in C. It supports a mix of built-in commands like `cd`, `echo`, and `export`, along with features like pipes (`|`), input/output redirections (`<`, `>`, `>>`), and even heredocs (`<<`). It’s a lightweight replica of the Bash shell meant to give a behind-the-scenes look at how your terminal really works, from parsing and executing commands to handling signals and environment variables.

## Usage:
1. using the terminal type `make` in the project's directory
2. start the program with ```./minishell```
3. Utilize the shell as you would use a proper shell
